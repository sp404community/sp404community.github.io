## Стартовая заставка — это две картинки

При включении [[index|SP-404MK2]] после стандартной надписи "SP-404" появляется сначала 1-я картинка, скроется за случайными полосками, и проявится 2-я картинка прежде, чем сэмплер полностью загрузится. По дефолту 1-я картинка – иероглифы, а 2-я "MKII".

Картинки можно заменить на свои:
![Стандартная заставка](video/startup_custom.mp4)

Стартовые картинки **привязаны к активному проекту**. Если переключиться на другой проект, при включении SP станут видны кастомные картинки из нового проекта, или, если их там нет, то стандартные иероглифы и "MKII".
## Как сделать собственный дизайн

Два черно-белых изображения размером `128 x 64 px`. На чёрном фоне белые элементы.

Сохранить дизайны надо в формате BMP, монохромном (один канал, не RGB). Роланды [пишут](https://articles.roland.com/ultimate-guide-customizing-the-sp-404-mkii/), что битность допустима 1, 4, 8, или 24 бита, но у меня сработал только 1 бит: либо чёрный, либо белый, без оттенков серого. В других вариантах писал Unsupported format.

Назвать файлы `startup_1.bmp` и `startup_2.bmp` 

#### Подвох с форматами
На Mac у меня возникли сложности с получением BMP нужного формата. Нет под рукой Photoshop, есть только Inkscape, Affinity (оба не умеют выводить BMP). Поэтому сохранял в PNG без прозрачности 8-битный монохромный, и затем конвертировал PNG в BMP.

Пробовал в терминале стандартной утилитой `sips`, Image Magick'ом и скачанной программой XnConvert — все **не годятся**, создают RGB BMP. Поэтому счёл удобнее конвертнуть простым скриптом на Python. Сначала установить `pip install pillow`, и сам скрипт, который ожидает файлов `startup_1.png` и `startup_2.png` 

```python
from PIL import Image
from pathlib import Path

file_names = ["startup_1.png", "startup_2.png"]

for filename in file_names:
	source_file = Path(filename)
	bmp_filename = source_file.with_suffix(".bmp")
	img = Image.open(filename)
	img = img.convert("1") # 1-битный монохром
	img.save(bmp_filename)
	print("Saved:", bmp_filename)
```

## Загрузка файлов в Roland SP-404MK2

Файлы заставки живут в Проекте. Поэтому план такой:
1. экспортировать проект на SD-карту;
2. на компе на этой SD-карте заменить файлы заставки на свои;
3. импортировать этот проект назад в SP.

#### 1. Экспорт проекта на SD карту
`Shift + 14`, Export, Project, выбрать текущий проект, Enter

#### 2. Замена изображений в сохранённом проекте
Карточку вставить в комп. В папке `EXPORT/PROJECT` найти папку с проектом. Например, я экспортировал 7-й, и папка автоматически называется `P7_PROJECT_07` В ней есть подпапка `PICTURE` с картинками. Там и надо заменить два файла `startup_1.bmp` и `startup_2.bmp` на такие же с вашим дизайном.

#### 3. Импорт проекта с новыми картинками
SD-карту вставить в Roland SP-404MK2.
`SHIFT + 14`,  Import, Project, и выбрать, в какой номер проекта импортировать. Можно в тот же самый, перезаписав его.
Сначала покажет папку `Import`, в которой обновлённого проекта нет. Чтобы переключиться на папку `Export`, где лежит обновлённый проект, нажать `ROLL` - и выбрать папку с проектом. Как в примере выше, для 7-го проекта, папку `P7_PROJECT_07` 
Нажать `Enter`. Может спросить, перезаписать ли, если выбрана занятая ячейка проекта.

Когда импорт завершится, надо переключиться на этот проект `SHIFT + SUB PAD`, номер проекта. И можно выключить - включить дивайс, чтобы полюбоваться новой заставкой.
